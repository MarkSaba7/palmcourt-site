How to read a tennis scoreboard

A tennis scoreboard packs a whole match into two rows of numbers. Once you know what each column means, you can walk up to any court and tell who is winning, who serves next and how close the set is.

Written by the Palm Court team · Updated 26 October 2026 · 8 min read

Key takeaways

  • A scoreboard has one row per player or team: finished sets and the current set on the left, the points of the current game on the right.
  • The server's score is always called first, so "15-40" means the server has 15 and the receiver has 40.
  • Serve from the right-hand side when the number of points played in the game is even, and from the left when it is odd.
  • Players change ends after the first game and then after every second game. In a tiebreak they change after every six points.

This page is about reading the board and following the order of play. If you still need the basics of how a point becomes a game and a game becomes a set, start with tennis scoring explained and come back.

One row per player, three kinds of number

A scoreboard, whether it is a courtside display, a television graphic or a flip-card at the club, is a small grid. Each player or team has a row. Reading from left to right you pass the sets already finished (each box shows how many games that player won in that set), then the set in progress, and last the points of the game being played now. Finished sets keep their final count, so the board also tells the story of the match.

Most matches are decided over three sets: the first player to win two sets wins the match. Some events use five sets, and a one-set match, like the ones you play in Palm Court, has just one column of games before the points. A dot or a small ball beside a name marks who is serving. If a board has no marker you can still work it out, because the serve passes to the other player after every game.

Calling the score

The server's score always comes first. When the server has won one point and the receiver none, the score is "fifteen-love", not "love-fifteen". The same rule holds on the umpire's microphone and in a friendly match where the server calls the score out before each serve. Ties inside a game are called "all": "fifteen-all", "thirty-all". Forty-all is the exception and is called deuce.

CallWhat it means
15-0 ("fifteen-love")The server has won one point and the receiver none.
0-30 ("love-thirty")The receiver has won two points and the server none.
30-allBoth players have two points.
40-30The server is one point from winning the game.
30-40The receiver is one point from winning the game: a break point.
DeuceThree points each. Someone must now win two points in a row.
Advantage in / advantage outThe server (in) or the receiver (out) has won the point after deuce and is one point from the game.

A game point, set point or match point is a point that would finish that game, set or match if the leading player wins it. A break point is a game point for the receiver. To hold is to win your own service game, to break is to win a game on your opponent's serve, and to break back is to win a game on your opponent's serve right after they have broken you. Winning a game without losing a point is a love game, and a set won 6-0 is sometimes called a bagel.

Who serves, and from which side

Before a match the players spin a racket or toss a coin. The winner may choose to serve or to receive, or which end to start from, and the other player chooses what is left. After that, serving alternates every game, all match long. The player who did not serve the last game of one set serves the first game of the next.

Within a game the server starts every game from the right-hand side of the baseline (the deuce court) and aims at the diagonal service box, then alternates sides after each point. You never need to ask which side comes next, because the score tells you:

  • Add up the points played in the game. Even (0, 2, 4, 6...) means serve from the right. Odd (1, 3, 5...) means serve from the left.
  • At 30-15 three points have been played, so the server stands on the left. At 30-30 four have been played: right.
  • This is where the names come from. Deuce means three points each, six in all, and every later deuce is an even total as well, so deuce is always played from the right, the deuce court. Advantage points are always an odd total, so they are played from the left, the ad court.

The same arithmetic works in doubles and in a tiebreak. It is also the quickest way to settle an argument about whether the server is on the right side. For how to hit the serve itself, see how to serve in tennis.

When players change ends

Wind and sun can favour one end of the court, so players swap ends to share them out. They change after the first game of a set and then after every second game (after games 1, 3, 5 and so on). The pattern carries over from set to set. A set that finishes 6-3 has nine games, an odd number, so the players change ends before the next set begins. A set that finishes 6-4 has ten games, so they do not change at the end of it and swap after the first game of the next set instead. There is a short rest at each change, and the longest break is between sets.

Tiebreaks: scoring and serving order

When a set reaches 6-6 it is normally settled by a tiebreak, a special game scored 1, 2, 3 and so on instead of 15, 30, 40. The first player to reach seven points wins it, but must be two points clear, so a tiebreak can run to 8-6, 9-7 or longer. Winning it wins the set 7-6.

The serving order is the part people forget. The player due to serve serves the first point from the right. After that the opponent serves two points, starting from the left, then the first player serves two, and so on, with each server's pair alternating sides. Players change ends after every six points.

The last two details: after a tiebreak the player who received first in it serves first in the next set, which keeps serve alternating as usual. And a set decided by a tiebreak is written with the loser's tiebreak points in brackets. A tiebreak won 7-4 makes the set score 7-6(4); one won 10-8 makes it 7-6(8).

Formats you will meet

FormatHow it differs
No-ad scoringAt deuce one deciding point is played, usually with the receiver choosing which side to receive. Common in college tennis, in doubles on tour and in many club leagues, because it shortens games.
Match tiebreakA first-to-10 tiebreak (two points clear) replaces the deciding third set. Very common in doubles and in club competitions.
Advantage final setNo tiebreak in the deciding set: play goes on until one player leads by two games.
Short setsThe first to four games takes the set, with a tiebreak at a smaller score. Popular for beginners and for quick evening matches.

If a match uses anything other than the standard rules, the players should agree on it before the first serve. Leagues and tournaments publish theirs.

Keeping score at the club

Most club matches have no umpire, so the players keep score between them. The habit that prevents nearly every dispute is simple: the server calls the score out clearly, server's number first, before each serve, and the receiver speaks up straight away if they disagree. If you cannot agree, go back to the last score you both remember and carry on from there. On line calls, you decide the balls that land on your side of the net. Call a ball out only if you clearly saw space between it and the line, because the rule is that a ball touching any part of the line is good, and any real doubt goes to your opponent.
