Tennis scoring explained

Tennis counts oddly, but the logic is simple once you see it as a ladder. Here is the whole system, and exactly how Palm Court applies it.

Written by the Palm Court team · Updated 12 October 2026 · 4 min read

Points: love, 15, 30, 40

A match is made of points, points make up games, and games make up a set. Inside a game, the score does not go 1, 2, 3. It goes 0 (love), 15, 30, 40. The first player to win four points wins the game, provided they are two points clear.

If both players reach 40, the score is deuce. From deuce, the player who wins the next point has the advantage (the scoreboard shows AD). Win the following point and you win the game. Lose it and the score goes back to deuce. A game can go to deuce many times; that is why close games feel so tense.

Serving

One player serves for a whole game, then the other serves the next game, and so on. The server has two chances at each point. A serve must land in the diagonal box on the other side of the net. If the first serve is a fault, a second serve follows. Two faults in a row is a double fault and the server loses the point. A serve that clips the net and still lands in the box is a let and is replayed.

The server starts each game from the right-hand side (the deuce court) and alternates sides after every point. In Palm Court the umpire calls the score aloud with the server's score first, so "Fifteen, love" means the server has one point and the receiver none.

Games and sets

Games add up to a set. In a normal set, the first player to win six games wins it, as long as they lead by two (6-4 is a win, 6-5 is not yet). If the games reach 6-6, the set is decided by a tiebreak.

The tiebreak

A tiebreak is a special game with simple numbers. Points are counted 1, 2, 3 and so on. The first player to seven points wins, but again by two clear points, so 7-5 wins and 7-6 does not. The serve rotates in a particular pattern: one player serves the first point, then the opponent serves the next two, then the first player serves two, and so on. The server alternates sides on every point.

Palm Court's three formats

A match in Palm Court is one set, and you choose its length in Match setup:

The tiebreak at the end of a short or full set is the same seven-point tiebreak described above. The format also changes your rewards: a tiebreak pays about a third of what a short set pays (35%), and a full set pays 60% more (160%). Winning against a harder CPU level multiplies the reward too: Club by 1.25 and Pro by 1.6. See the progression guide.

Doubles uses the same scoring. Each side has two players, and they take turns serving, and the wide court (with the doubles alleys) is in play for rallies; a serve must still land in the normal service box. See couch play and doubles.

Reading the scoreboard in the game

  • The scoreboard shows games for each player and the current points in the game, using 0, 15, 30, 40 and AD. In a tiebreak it shows plain numbers.
  • A marker beside the server's name shows who serves.
  • The umpire's voice calls the score after each point and the games when a game ends.
  • The word Out, Net, Ace, Winner or Double fault flashes to say how the point ended.

Why it matters for tactics

Not all points are equal. Winning the first point of a game matters less than the point at 30-40 or at deuce. Play your safest good shot on big points, because an unforced error hands the point straight to your opponent. The groundstroke guide shows how to build a point you can win without taking big risks.
